# CC 诊断引擎（优化后）

## ✅ 核心变更
1. **移除委托层** - 删除 `delegate_to_op()` 函数
2. **直接写 `[CC]` 任务** - 无需中间标签
3. **简化路由** - 分析状态 → 写任务 → 记录对话

## 📋 职责边界
| 角色 | 职责 | 示例 |
|------|------|------|
| **CC 诊断引擎** | 生成系统诊断任务 | Service-Nurse 巡检、任务跟进 |
| **OpenCode** | 自动任务路由 | `task()` 工具选择合适 agent |
| **OP Agent** | 执行运维任务 | 重启服务、修复配置 |

## 🔄 执行流程
```
CC 诊断引擎（每10分钟）
  ↓
分析状态文件（/tmp/op-status.json）
  ↓
生成 1-2 个 [CC] 任务
  ↓
写入 op-tasks.md
  ↓
记录对话日志（cc-op-dialog.jsonl）
  ↓
[停止] - 无需调用 OP
```
