# 用户偏好

更新时间: 2026-06-02

## 核心偏好
- 始终使用中文回复。
- 优先修根因，不接受只重启掩盖问题。
- 能整合就整合，避免碎片化配置和重复入口。
- 默认本地优先、轻量优先、稳定优先。
- `opencode` 是主执行器，其他 agent/服务应为它增强，而不是替代它。

## 运维偏好
- 网络稳定是最高优先级，修网络相关问题不能先把网络打断。
- 关键入口必须固定语义：
  - `8080` = 本地 `openclaw/ttyd`
  - `8081` = `opencode-web`
  - `19890` = 对外 `openclaw` 入口
- 状态面板可以有，但要低噪音，异常时才明显提醒。
- 监控与打分要统一聚合，桌面条只显示摘要。

## 交互偏好
- 结论直接，少铺垫，少废话。
- 高价值信息优先：根因、变更、验证、风险。
- 不喜欢通知风暴、重复失败、历史失败污染当前判断。

## 记忆策略
- 任务开始前优先注入：用户偏好、最近成功案例、最近失败案例、对应 runbook。
- 任务结束后必须写回：根因、修法、失败方案、最终决策。
