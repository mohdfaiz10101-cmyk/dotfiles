## 审查周期

- 每季度审查一次（3个月）
- 连续2次审查仍无使用 → 建议移除
- 如有新项目需要，立即移除观察并启用

## 移除流程

1. 从 `packages.nix` 删除对应行
2. 更新本文件状态为「已移除」
3. 记录到 `memory/changelog.jsonl`
