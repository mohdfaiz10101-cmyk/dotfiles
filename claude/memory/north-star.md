> **MUST READ**: 每次 CC/OP 新会话启动时必须读此文件。

## 终极目标（用一句话）

**一个以你为中心的个人 AI 操作系统：你的所有信息（微信/邮件/文件/任务）自动流入，AI 自动处理、关联、执行，你只需要做决策。**

不是工具箱，不是聊天机器人，是**你的第二个大脑 + 第一个执行者**。

---

## 最终形态（2026 年底目标）

### 你坐在电脑前看到什么
```
┌─────────────────────────────────────────────────────────┐
│  port 3000 — 你的 AGI 控制台（唯一入口）               │
├─────┬───────────────────────────────────────────────────┤
│侧栏  │  [今日摘要] 微信 3 条未回 / 2 个任务到期         │
│     │  [知识图谱] 张三 ←→ ABC贸易公司 ←→ 询价任务      │
│     │  [对话室]   CC: 已处理询价 / OP: CRM 已更新       │
│     │  [微信]     自动回复状态 / 未处理消息              │
│     │  [CRM]      今日新增联系人 / 跟进提醒              │
└─────┴───────────────────────────────────────────────────┘
         ↓ 底部输入栏（Universal Bar）
    拖入任何东西 → 自动处理，不需要告诉AI怎么做
```

### AI 在后台做什么（你看不到但感受得到）
- 微信消息进来 → 自动分类 → 客户询价自动建档+回复草稿
- 你拖入名片照片 → 自动识别联系人 → 存入 CRM
- 你提到一个人名 → 自动关联历史对话/任务/公司
- 每天早上 → 推送今日简报（未回消息+待办+异常）
- 你的习惯 → 被记录学习 → 下次主动准备

## 商业定位（为什么要建这个）

你的核心业务：**外贸/采购**
- 每天要处理大量客户询价（微信/邮件）
- 需要跟进大量联系人（记不住谁在哪个阶段）
- 需要快速报价（FOB/MOQ/样品/交期）
- 需要管理供应商关系

**AI OS 给你的核心价值**：
1. 不漏单 — 每条询价自动建档，不会忘
2. 快速响应 — 询价意图识别后自动生成回复草稿
3. 关系图谱 — 客户/供应商/产品的连接一目了然
4. 解放注意力 — 琐事交给 AI，你专注决策

## 技术架构（最终态）

```
数据来源层：
  微信（UOS+Wine）/ 邮件 / 文件 / 网页 / 手动输入

           ↓ Universal Intake（统一入口）

处理层：
  实体提取（GLM-4.6v-flash）
  意图分类（询价/跟进/内部/闲聊）
  技能路由（wechat-skill / crm-skill / doc-skill）

           ↓

存储层：
  Twenty CRM — 联系人/公司/机会
  Letta — 语义记忆+实体关联图
  ChromaDB — 向量检索
  op-tasks.md — 待执行任务队列

           ↓

执行层：
  CC（Claude Sonnet）— 规划/编码/架构
  OP（OpenCode GLM）— 运维/定时/执行
  wechat-agent — 微信自动回复
  macg-brain — AGI调度循环

           ↓

展示层：
  port 3000（agi-frontend）— 唯一用户界面
  对话室 — CC/OP/用户实时互看
  知识图谱 — 实体关联可视化
  晨报 — 每日主动推送
```
