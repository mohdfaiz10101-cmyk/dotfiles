## [2026-08-10T23:05:00+08:00] NetBird foreground safety and phone network fallback state

NetBird must not be foregrounded by background timers. `phone-netbird-ensure`
is monitor-only unless both `PHONE_NETBIRD_AUTO_REPAIR=1` and
`PHONE_NETBIRD_ALLOW_FOREGROUND=1` are set for an explicit short repair window.
`adb-phone-keepalive.sh` must not run `monkey -p io.netbird.client` unless
`ADB_KEEPALIVE_ALLOW_NETBIRD_FOREGROUND=1` is set. Routine timers should keep
ADB/FRP/NetBird routes and Android background permissions healthy without
stealing the current app foreground.

Verification:

```bash
systemctl --user show phone-netbird-ensure.service adb-phone-keepalive.service -p Environment -p ExecStart --no-pager
adb -s 127.0.0.1:15555 shell 'dumpsys window | grep -E "mCurrentFocus|topResumedActivity" | head -5'
~/.local/bin/phone-network-stabilize status
```

Current healthy fallback evidence from 2026-08-10: FRP ADB true, NetBird ADB
true, mihomo proxy true, Play Store proxy true, DuckDNS `19976` returns `200`.
When the phone is on portable Wi-Fi or hotspot, LAN ADB false can be expected;
