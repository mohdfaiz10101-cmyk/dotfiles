系统操作指南

一、APK 开发（启动器 App）

方案 Web PWA → 安卓 APK

启动器已经是 PWA，可以直接安装到手机主屏幕：

1
手机浏览器打开启动器（需同一网络）
http://电脑IP:9875/launcher.html
2
Chrome：菜单 → 「添加到主屏幕」
Firefox：菜单 → 「安装」
3
手机主屏幕出现「启动器」图标，点击即用
PWA 模式无需编译，秒装。全屏运行，和原生 App 体验一致。

如果要打包成真正的 APK：

1
安装 Android SDK（已加入 NixOS 配置）
2
用 Capacitor 打包
cd ~/launcher && npx cap init && npx cap add android && npx cap open android

二、APK 管理（推送到手机）

工具 ~/launcher/apk-manager.sh

1
把 APK 文件放到
~/APKs/
2
扫描设备
~/launcher/apk-manager.sh scan
3
安装到手机
~/launcher/apk-manager.sh install 文件名.apk
4
批量安装所有 APK
~/launcher/apk-manager.sh batch
确保手机 USB 调试已开启，或 WiFi ADB 已连接

三、项目自动分类

工具 ~/launcher/desktop-auto-sort.sh

新建项目放到 ~/Projects/，自动识别类型并在桌面创建快捷方式。

1
手动扫描一次
~/launcher/desktop-auto-sort.sh scan
2
后台持续监控
~/launcher/desktop-auto-sort.sh watch &

支持自动识别：安卓、Flutter、Rust、Node.js、Python、Go、Nix、Docker 项目

四、磁盘自动迁移

工具 ~/launcher/disk-auto-migrate.sh

1
查看磁盘状态
~/launcher/disk-auto-migrate.sh status
2
预览迁移（不实际执行）
~/launcher/disk-auto-migrate.sh dry-run
3
执行迁移
~/launcher/disk-auto-migrate.sh run
4
后台持续监控（每 10 分钟检查）
~/launcher/disk-auto-migrate.sh watch &
当前 /mnt/data 使用率 86%，建议执行一次迁移或清理

六、远程串流（Sunshine + Moonlight）

方案 手机/平板/VR → 主机低延迟串流

1
首次访问 Sunshine Web 配置面板
https://localhost:47990
2
设置管理员用户名和密码
3
手机/平板安装 Moonlight（Play 商店搜索即可）
4
Moonlight 自动发现主机（同一网络），点击配对
5
在主机上确认配对 PIN 码
使用 NVIDIA RTX 3060 Ti 硬件编码，延迟极低。支持 4K@60fps。
首次使用可能需要重新登录或重启让 Sunshine 服务生效

七、Cockpit 系统管理面板

用途 触屏 Web 管理系统：磁盘、服务、日志、终端、网络

1
浏览器打开
http://localhost:9090
2
用系统账号登录（charlie / 密码）
无需终端即可管理系统：查看磁盘、管理 Docker、重启服务、查看日志

八、Web 终端（ttyd）

用途 浏览器里直接用终端，适合平板/手机操作

1
浏览器打开
http://localhost:7681
直接进入 zsh shell，支持所有终端操作。深色主题，16px 字体。
终端端口用途
Claude Code7690CC 对话
Gemini CLI7691Gemini 对话
OpenCode7692OP 任务执行
Aider7693批量代码重构
MACG LangGraph7694认知图谱 / 自愈 / 进化

1

十、Tailscale 外网组网

用途 从外网（手机/平板/VR）安全连接主机，无需端口转发

1
首次登录 Tailscale
sudo tailscale up
2
浏览器打开登录链接，用 Google/GitHub 账号登录
3
手机安装 Tailscale App（Play 商店），同一账号登录
4
查看分配的内网 IP
tailscale ip
5
手机浏览器用 Tailscale IP 访问所有本地服务
Moonlight 也可以通过 Tailscale IP 连接 Sunshine，实现外网低延迟串流

十一、Syncthing 文件同步

用途 全设备实时文件同步（密码库、文档、照片）

1
打开 Syncthing Web 管理界面
http://localhost:8384
2
手机安装 Syncthing（Play 商店），扫码配对
3
添加同步文件夹（建议先同步密码库 ~/密码.kdbx）
P2P 加密传输，不经过第三方服务器。局域网直连更快。
KeePassXC 数据库通过 Syncthing 同步到手机 KeePassDX

十二、KDE Connect

用途 剪贴板同步、通知推送、文件传输、远程输入

1
手机安装 KDE Connect App
2
同一 WiFi 网络下自动发现，点击配对
3
启用需要的功能：剪贴板共享、通知同步、远程输入
复制文本自动同步到手机，手机通知推送到桌面
