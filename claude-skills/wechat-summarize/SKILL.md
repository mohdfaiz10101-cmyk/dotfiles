# 微信群聊摘要

## 场景
为未读群消息生成摘要，提取关键信息、决策、行动项。支持：
- 单群摘要（指定群聊）
- 每日全量摘要（所有活跃群）
- 关键词过滤摘要（只看特定话题）

## 前置条件
- 微信 MCP Server 运行中

## 工作流

### 1. 获取消息
```
使用 MCP 工具: get_recent_messages
参数: room_id="群ID", limit=100
```

### 2. 消息预处理
- 过滤系统消息（入群、撤回等）
- 合并同一人连续发言
- 识别引用/回复关系
- 按时间排序

### 3. 摘要生成
输出格式：
```
📋 [群名] 消息摘要 (N条未读)
━━━━━━━━━━━━━━━━
📌 关键话题：
  1. [话题1] — 参与者A, B
  2. [话题2] — 参与者C, D

✅ 决策/结论：
  - [决策1]
  - [决策2]

🔥 行动项：
  - [ ] @某人: 待办事项1
  - [ ] @某人: 待办事项2

💬 重要发言：
  > 张三: "原话引用..."
  > 李四: "原话引用..."
```

### 4. 存储摘要
- 写入 `~/.local/share/hyperchat/data/wechat_digests.db`
- 格式：room_id, date, summary, key_topics, action_items

## 每日摘要模式
触发条件：每天 20:00 自动执行
流程：
1. 遍历所有活跃群聊（最近 24h 有消息的群）
2. 为每个群生成摘要
3. 合并为每日总摘要
4. 发送到指定群或私聊

## 关键信息提取规则
- **决策**：包含"决定""确认""就这么定了"等关键词
- **行动项**：包含"我来""负责""跟进""待办"等关键词
- **重要发言**：被 3+ 人回复/引用的消息
- **时间相关**：包含具体日期/时间的安排
