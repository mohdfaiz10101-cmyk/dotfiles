# 微信群聊智能回复

## 场景
在微信群聊中，AI 仅在以下情况主动回复：
1. 被 @提及
2. 关键词触发（如"报价""技术问题""AI"）
3. 群主/管理员直接对话

## 前置条件
- 微信 MCP Server 运行中
- 已知群聊 room_id

## 工作流

### 1. 获取群消息
```
使用 MCP 工具: get_recent_messages
参数: room_id="群ID", limit=50
```

### 2. 判断是否需要回复
- 检查是否被 @提及（匹配微信号/昵称）
- 检查关键词触发列表
- 检查消息时间（只处理最近 5 分钟内的消息）

### 3. 生成回复策略
| 场景 | 策略 |
|------|------|
| @AI 提问 | 直接回答问题 |
| 关键词触发 | 简短补充信息 |
| 群主对话 | 正常回复 |
| 闲聊 | 不回复 |
| 广告/链接 | 不回复 + 记录 |

### 4. 发送回复
```
使用 MCP 工具: send_text_message
参数: wxid="群ID", content="回复内容"
```

## 群聊回复规则
- **频率限制**：同一群 30 秒内最多回复 1 次
- **长度限制**：≤ 300 字（群聊不宜长篇大论）
- **格式**：用换行分段，避免大段文字墙
- **语气**：轻松专业，可适当使用表情

## 群聊类型识别
```
使用 MCP 工具: get_room_members
参数: room_id="群ID"
```
- 成员 < 10 → 工作群（专业回复）
- 成员 10-50 → 业务群（平衡专业和亲切）
- 成员 > 50 → 大群（只回复 @提及，避免刷屏）

## 示例
```
群消息: "@AI助手 请问你们支持定制开发吗？"
AI回复: "@提问者 支持的！我们有专门的定制开发团队。
需要了解：
1. 大概的功能需求
2. 预期交付时间
3. 预算范围
可以私聊我详细沟通 😊"
```
