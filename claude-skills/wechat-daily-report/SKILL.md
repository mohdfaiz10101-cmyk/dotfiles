# 微信每日沟通报告

## 场景
每天晚上 20:00 自动生成当日微信沟通报告，包括：
- 消息统计（发送/接收/各群活跃度）
- 客户互动摘要
- 待回复/待跟进事项
- 关键决策和约定

## 报告格式

```
📊 微信日报 — 2026-04-16（周四）
━━━━━━━━━━━━━━━━━━━━━━━━━━

📈 今日数据
  收到消息: 156 条 | 发送消息: 43 条
  活跃群聊: 5 个 | 私聊联系人: 8 人
  平均响应时间: 2.3 分钟

👥 重要客户互动
  1. 张总 (VIP客户)
     - 询价产品B批量价
     - 约定明天发正式报价单
     ⚠️ 待办: 明早10点前发报价

  2. 李经理 (供应商)
     - 确认交货期延期至周五
     - 已同意补偿方案

📋 群聊摘要
  • 项目A讨论群 — 确认了技术方案v2
  • 客户服务群 — 处理了3个售后问题
  • 行业交流群 — 分享了市场趋势报告

⏰ 待办事项
  - [ ] 明早10点: 给张总发产品B报价
  - [ ] 周五: 跟进李经理交货
  - [ ] 本周: 更新CRM中3个新联系人信息

📊 本周趋势
  消息量: ████████░░ 80%
  新客户: +2
  待跟进: 5 人
```

## 工作流

### 1. 数据收集
```
使用 MCP 工具: get_recent_messages
遍历所有私聊和群聊，收集 24h 内消息
```

### 2. 数据分析
- 统计消息数量和方向
- 识别高频联系人
- 提取行动项和承诺
- 计算响应时间

### 3. 报告生成
- 按优先级排序（客户 > 群聊 > 其他）
- 标注待办和截止时间
- 与前日数据对比趋势

### 4. 分发
- 默认：输出到 OpenCode 终端
- 可选：发送到指定微信群/文件传输助手
- 归档：`/mnt/ai/apps/wechat-agent/data/reports/YYYY-MM-DD.md`

## 自动触发
通过 opencode scheduler 配置：
```json
{
  "name": "wechat-daily-report",
  "schedule": "0 20 * * *",
  "prompt": "/wechat-daily-report"
}
```
