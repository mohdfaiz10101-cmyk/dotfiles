# MCP 浏览器实时同步扩展

## ✅ 同步的内容

- **书签** - 实时同步，所有书签立即共享
- **历史记录** - 所有访问的网页自动记录
- **打开的窗口/标签页** - 查看其他设备正在浏览什么
- **Cookies** - 登录状态自动共享
- **浏览器设置** - 偏好设置同步

## 🚀 安装方法

### NixOS（Zen/Firefox/Floorp）

1. 打开浏览器，地址栏输入：`about:debugging`
2. 点击「临时扩展程序」
3. 点击「载入临时附加组件」
4. 选择：`~/launcher/public/browser-sync-extension/manifest.json`
5. 完成！

### Windows（Zen/Firefox）

1. 下载扩展：`http://192.168.123.1:9875/browser-sync-extension.zip`
2. 解压到任意位置
3. 打开浏览器，输入：`about:debugging`
4. 载入 `manifest.json`

## 📍 服务器地址

**NixOS 本机**：已自动配置（`http://localhost:9978`）

**Windows/其他设备**：
1. 编辑 `background.js` 第2行
2. 改为：`const SYNC_SERVER = 'http://192.168.123.1:9978';`
3. 重新加载扩展

## 💡 使用说明

### 自动同步（默认开启）
- 添加书签 → 立即同步到所有设备
- 访问网页 → 历史记录自动同步
- 打开/关闭标签 → 其他设备实时看到

### 手动操作
- 点击扩展图标 → 打开控制面板
- **⬆️ 推送** - 立即将所有数据发送到其他设备
- **⬇️ 拉取** - 从其他设备获取最新数据

### 查看其他设备正在浏览的内容
访问：`http://localhost:9978/sync/tabs`（或用 NixOS IP）

## ✨ 特点

- 🔒 **完全私有** - 数据不经过第三方服务器
- 📡 **局域网同步** - 速度快，无需互联网
- 🚀 **实时更新** - 每次操作立即同步
- 🌐 **跨平台** - NixOS、Windows、手机都支持
